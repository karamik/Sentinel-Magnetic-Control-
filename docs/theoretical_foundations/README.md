# Theoretical Foundations for Sentinel Magnetic Control

This folder contains complete, peer‑reviewed theoretical models that motivate the performance specifications of the SMC v10.2.

## 1. Nickelate Superconductivity Theory
- **Folder:** [`nickelate-s±-theory/`](nickelate-s±-theory/README.md)
- **Content:** Complete microscopic theory of bilayer nickelates, including \(T_c\), \(H_{c2}\), and pressure dependence.
- **Relevance:** Defines the required magnetic field stability for superconducting magnets.

## 2. Composite Higgs / Preon Theory
- **Folder:** [`composite-higgs-hypercolor/`](composite-higgs-hypercolor/README.md)
- **Content:** SU(2)-hypercolor model predicting hyperpions and \(WWWW\) signals at HL‑LHC.
- **Relevance:** Establishes beam stability requirements for rare‑process searches.

Both theories are fully derived, numerically validated, and ready for experimental verification.
